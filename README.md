# THE WATCHDOG

> A sphere of **UD0** — the ROOT0 universe / biosphere. Domain: **SKYNET**.

THE WATCHDOG &mdash; David Lee Wise / ROOT0, with AVAN. A self-halting system: an agent runs while a watchdog holds bounds and a heartbeat timeout &mdash; let the metric drift past the band or stall the heartbeat, and the watchdog trips, <b>freezing to a safe state</b> rather than letting it run wrong. &#9670; GREEN/LIT the trip condition is a checkable predicate evaluated every frame &mdash; |metric| &gt; bound OR (t &minus; last_heartbeat) &gt; timeout &rArr; FREEZE &mdash; and on trip it reports which clause fired; this is real, load-bearing engineering (hardware watchdog timers, runtime invariant monitors, liveness dead-men). AMBER the drifting metric is a synthetic random walk and &lsquo;inject fault&rsquo; scripts the breach &mdash; a stand-in for whatever real signal you&rsquo;d wire in. &#9670; A watchdog freeze does not <i>fix</i>, it <b>stops</b>: freeze&ne;finish, with the fault named and re-arming a new decision.
